# Adventure Time Mod

The Adventure Time Mod is a Minecraft mod that teleports players into the world of Adventure Time, specifically the Land of Ooo. This mod introduces a new dimension with unique biomes, structures, and entities inspired by the Adventure Time series. It includes a teleportation command and a GUI to facilitate the journey to the Land of Ooo.

## Install

1. Download the mod file from the GitHub repository or the EnderDevelopment marketplace.
2. Place the downloaded file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure the mod is loaded.

## Use

1. Open the Minecraft chat and type `/teleport_to_ooo` to teleport to the Land of Ooo.
2. Alternatively, use the teleportation GUI by opening the inventory and interacting with the teleportation item.
